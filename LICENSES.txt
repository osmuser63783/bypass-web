Overpass API
------------
Bypass reimplements the query language of the Overpass API (https://github.com/drolbr/Overpass-API).
src/geometry.js, src/ovindex.js, src/areas.js, src/expr.js, src/localize.js and src/render.js port parts
of its C++ source.
Copyright (C) 2008-2018 Roland Olbricht et al. AGPL-3.0-or-later.

Maps and styling
----------------
Basemaps: OpenFreeMap (https://openfreemap.org, OpenMapTiles schema) and OpenStreetMap's raster tiles,
credited on the map. The front-matter styling follows the format documented by Overpass Ultra
(https://overpass-ultra.us); no Ultra code is used.
